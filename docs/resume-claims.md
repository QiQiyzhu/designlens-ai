# What can and cannot be claimed

## Supported by artifacts and reproducible software behavior
- Designed an evidence-to-decision product workflow spanning research, opportunities, AI feasibility, versioned execution, evaluation and experiment planning.
- Implemented a React/TypeScript + FastAPI/SQLite local MVP with four-format import, source-linked exact extracts and explicit human decisions.
- Implemented prompt/workflow version history, diff, rollback, durable review gates and execution traces.
- Built an actual synthetic fixture evaluation pipeline, with per-case failures, dataset hash, timing, nullable provider usage and human ratings.
- Prepared official-source competitor analysis, research/consent/observation templates, PRD, metrics, SQL/Python analysis, experiment protocol and a Figma-ready design specification.
- Can cite exact automated check counts **only from the current checked-in report** and with the words “automated tests” or “synthetic development cases”.

Suggested Chinese résumé wording:
“设计并实现 DesignLens AI 产品决策原型，打通 Evidence → Opportunity → Feasibility → Workflow → Evaluation → Experiment；实现证据溯源、人审确认、Prompt/Workflow版本管理与可复现评测，并准备 ARC//SHIFT 定性用户研究和非AI/AI方案对照实验。真实用户验证待开展。”

## Not supported; must not claim
- Interviewed 8–12 people, surveyed users, found top three real player problems or measured willingness to pay. Those are prepared plans; actual supplied participant data is zero.
- Improved activation, retention, revenue, conversion, task time, model hallucination rate or development productivity by any percentage.
- Achieved statistically significant A/B results or product-market fit.
- Compared real commercial models when the report used deterministic extraction.
- Built or evaluated an autonomous Agent or live MCP integration; these are outside this MVP.
- Led a staffed PM/Design/Engineering/Data team. Role allocation documents are a planning exercise.
- Created Figma frames or learned Figma solely because a generated web prototype exists.
- Shipped a secure multi-tenant production service, passed a security certification, or validated business outcomes.

## Evidence required to upgrade a claim
For user findings: consented raw sessions, actual sample, independent participant IDs, coding and counterexamples. For product improvement: baseline, preregistered measures, real allocation/observations and uncertainty analysis. For model improvement: fixed independent dataset, model/version, actual calls, cost/latency and blinded human review. For personal ownership: explain design tradeoffs and reproduce the behavior without relying on generated prose.
