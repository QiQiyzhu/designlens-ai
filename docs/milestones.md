# Milestones — project planning exercise

Roles below are planning responsibilities, not fictional employees. The project author used AI-assisted coding and documentation; no six-person team is claimed.

| Gate | PM | Design | Frontend / Backend | AI Engineer / Data | Exit evidence |
|---|---|---|---|---|---|
| Discovery prepared | Hypotheses, interview plan, competitor review | Task journey | Import contract review | Evidence/eval formats | 13 phase-0 documents before main coding |
| Decision MVP | Scope and human gates | Six-screen spec | Local evidence-to-experiment flow | Extractive baseline, SQL | Reproducible tests and demo |
| Real qualitative pilot | Recruitment, consent, analysis | Observe tasks | Fix observed blockers | Dedup/coding audit | Actual raw records, not synthetic fixtures |
| Intervention selection | Top three problems, one MVP | UI/rule alternative | Bounded implementation | Frozen dataset and provider test | Human decision with evidence |
| Product evaluation | Pre-register protocol | Moderator-free task flow | Instrumented release | Real outcome analysis | Limitations and build/revise/stop decision |

Dates for recruitment and fieldwork remain unscheduled. Engineering completion is not discovery validation. No milestone may be marked as having interviewed or retained users on the basis of a local demo.
