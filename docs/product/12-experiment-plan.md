# Experiment plan

**PENDING REAL USER RESEARCH**. No allocation, participant response or effect size exists yet.

## Gate 1: problem and usability pilot
First observe ARC//SHIFT tasks in 8–12 new players. Use tasks with concrete success criteria: describe weapon differences, explain one build interaction, choose a route and name its resource consequence. Record completion, decision time, explanation quality, assistance and confidence. This is a qualitative pilot; it does not establish population prevalence or significance.

## Gate 2: candidate intervention
Only after selecting a supported problem, compare A: current interface; B: simpler text/contextual rule explanation; C: bounded AI explanation if feasibility justifies it. Do not make the AI arm mandatory. Freeze scenarios and factual catalog. Counterbalance task order for within-person usability exploration; do not call that a production randomized retention experiment.

Hypothesis template: “For [observed segment] during [task], [intervention] improves [primary measure] because [evidence-backed mechanism].” Primary measure: unaided task completion under a preregistered rubric. Secondary: decision time, explanation understanding, helpfulness, choice confidence and retention intention (intention is not actual retention).

Guardrails: incorrect advice, player override, longer task time, latency, cost, frustration and lost user control. Every suggestion includes why, trade-off and alternative; no automatic decisions.

## Decision rule
For the pilot: proceed only if recurring severe comprehension errors decrease without new critical errors and the participant can explain the trade-off. A disagreement requires examining recordings/notes, not averaging it away. If rules solve the observed problem, select rules. If evidence remains mixed, revise and repeat a qualitative round. Report raw counts and limitations; never “statistically significant” without an appropriately designed and executed study.

For a later powered test: choose one primary metric, estimate baseline from real data, define minimum useful effect, randomization unit, sample size calculation, sequential-look policy, duration and exclusion rules before launch. This project does not supply fabricated baselines or traffic forecasts. Maintain separate planned, running, observed and decided states; creating a protocol cannot advance the North Star count.
