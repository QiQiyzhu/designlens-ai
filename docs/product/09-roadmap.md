# Roadmap

This is a planning exercise. Effort is relative (S/M/L), not a promised team estimate. Impact is a hypothesis pending research.

| Horizon | Deliverable | Impact hypothesis | Effort | Risk | Dependency / exit gate |
|---|---|---|---|---|---|
| MVP | Four-format import, immutable source text and IDs | Makes claims inspectable | M | Imported sensitive data | Provenance rejection tests |
| MVP | Human insight review, opportunity and feasibility | Prevents model suggestions becoming decisions silently | M | Process friction | Complete decision task without moderator |
| MVP | Versioned bounded workflow and prompt diff | Reproduces an output | M | False confidence from a demo provider | Trace and error-path tests |
| MVP | Rule evaluation, analytics queries, experiment protocol | Separates software behavior from product outcomes | M | Synthetic metrics misread as business data | Visible dataset/source labels |
| V1 | Real ARC//SHIFT qualitative pilot and selected intervention | Tests a real problem | M | Recruitment bias | Consented 8–12 target sessions; actual count reported |
| V1 | Real provider benchmark and blinded human review | Tests language output beyond extraction | M | Cost, privacy, evaluator bias | Approved data and credentials; frozen cases |
| V1 | Export to existing PM workflow | Reduces duplication | M | Integration maintenance | Observed demand in pilot |
| V2 | Multi-workspace auth and hosted study support | Enables team adoption | L | Data isolation/security | Ownership model and security review |
| V2 | Connectors or read-only MCP | Reduces import effort | L | Permissions and stale evidence | Measured import friction |
| V2 | Agent execution only for demonstrated tool tasks | May reduce repetitive coordination | L | Compounding errors and review burden | Beats bounded workflow on a real task |

Not now: more charts, an AI avatar, automatic game advice, arbitrary remote tools, full Figma editing, enterprise billing and multi-agent orchestration. They do not resolve the unvalidated core problem. The owner must still make the six principal screens in Figma to practice design; the web prototype is reference material, not evidence of Figma proficiency.
